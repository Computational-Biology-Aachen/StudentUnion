# Mohamed's Code

## Phage Pipeline

In this directory you will find code that is part of Mohameds HIWi Work. 
The goal is, to create a software that takes a FASTA-file as an input and create an html-file as an output. 

The pipeline should:
- Sort nucleotides into genes
- Annotate genes
- Add Functional and structural predictions
